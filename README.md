## 📥 Локальная установка

Для локального запуска веб-приложения:

1. Клонируйте репозиторий
2. Запустите локальный сервер, указав корневой папкой директорию `/docs/`
3. Откройте приложение в браузере

## 🛠 Технологии

- **Основные технологии**: Unity + WebAR Foundation на базе MindAR
- **Технология распознавания**: Image Tracking
- **Используемые библиотеки**:
  - [PrimeTween](https://github.com/KyryloKuzyk/PrimeTween#support) - анимации
  - [MindAR Image Compiler](https://hiukim.github.io/mind-ar-js-doc/tools/compile) - компилятор изображений
- **Ассеты**:
  - [Simple UI Elements](https://assetstore.unity.com/packages/2d/gui/icons/simple-ui-elements-53276) - элементы интерфейса

## 🎯 Как работает приложение

Приложение построено на основе готовых материалов из примеров WebAR Foundation с следующими возможностями:

1. **Запуск сессии** - пользователь запускает среду MindAR для распознавания изображений
2. **Визуальное сопровождение** - появляется полупрозрачное изображение-подсказка для помощи в позиционировании камеры
3. **Распознавание** - при успешном обнаружении изображения подсказка исчезает (используются события `OnTargetFound`, `OnTargetLost`)
4. **Фотографирование** - пользователь может сделать несколько снимков
5. **Выбор фото** - возможность выбрать понравившееся фото из галереи для загрузки
6. **Приглашение** - при первом скачивании изображения предлагается посетить СоюзМультПарк с предоставлением ссылки

## ⚠️ Ограничения и известные проблемы

- **Зависимость от ракурса** - сильная зависимость качества распознавания от угла камеры (ограничение маркерной технологии)
- **Качество фото** - качество снимков ниже, чем в стандартном приложении "Камера" смартфона
- **Текущая функциональность** - в текущей версии реализовано только общее фото с 3 фигурами одновременно (имеется возможность расширения)
- **Погружение в AR** - из-за специфики технологии Image Tracking, интеграция 3D-объектов в реальный мир имеет ограниченную реалистичность
